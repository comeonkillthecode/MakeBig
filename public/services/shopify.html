What's included

Store setup and migration

New stores configured properly from day one, or moves from WooCommerce, Magento, Wix or a custom platform. That covers products, customers, order history, redirects, payments and shipping.

Shopify · Shopify Payments · Matrixify / custom import scripts

Custom themes

Themes built from scratch or heavily customised from Dawn, using Online Store 2.0 sections so your team can edit pages without a developer.

Custom apps for one store, or public apps for the Shopify App Store. Covers admin UI, theme app extensions, checkout extensions and webhooks.

Admin GraphQL API · Polaris · app extensions · React Router / Remix
